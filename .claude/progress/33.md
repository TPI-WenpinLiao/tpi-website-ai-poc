## 目前狀態

needs-design 階段一已出貨（PR #134），使用者 2026-10-26 加上 `design-approved` 並要求開始階段二。

已決定的做法（計畫確認時與階段一）：
- 只接 `/contact-us`；adapter 只做 log，只記表單 id、欄位名稱與時間，不記個資
- 送出成功導到 `/thanks`；Turnstile 可見 widget，預留框寬度 < 300px 用 compact，否則 flexible；使用者第一次 focus 進表單才載入 script
- 驗證規則表與 `validate()` 前後端共用（不用 zod，避免前端多載入 schema 套件），伺服器結果為準；順序：設定檢查 → 欄位驗證 → Turnstile → adapter
- `TURNSTILE_SECRET_KEY` 沒設定時一律拒絕（fail closed）；site key 讀 build 時的 `PUBLIC_TURNSTILE_SITE_KEY`，沒設定時用 Cloudflare 公開的測試 key
- 動態錯誤訊息的元素預先 render（隱藏），scoped 樣式才會套用；錯誤摘要用 `<template>` 複製
