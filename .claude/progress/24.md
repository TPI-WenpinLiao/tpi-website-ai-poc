查到的根因：
- 第 1 次 CI（ubuntu-latest runner＋`playwright install --with-deps`）與第 2 次（`mcr.microsoft.com/playwright:v1.63.0-noble` container，補裝雲端多出的字型）差異數字完全相同
- 診斷（`.github/scripts/visual-diagnose.mjs`，暫時的，決定後刪除）：dist hash、字型清單、Chromium 153.0.8010.12 都相同。`fc-match sans-serif` 雲端是 Inter（雲端自訂的 `/etc/fonts/conf.d/56-prefer-inter.conf`）、CI 是 DejaVu；雲端另有 `12-unhinted-grayscale.conf`。在雲端拿掉這兩個檔、改 `LANG`、`TZ` 都重現不了，已還原
- `/templates/content` 768px：唯一不同的元素是「2020 - 2022」那段（本機 326.3px、CI 353.4px，多一行）。本機該段「Excellence Awards、2022 創新商務獎、」那行只剩 0.78px 空間，CI 上換行
- 雲端 CPU 是 Intel Xeon，CI runner 是 AMD EPYC 9V45：推論是字寬的極小差異讓貼近換行門檻的行在兩邊換法不同，任何環境設定都對不齊
