## API 經濟大商機！透過開放API提供主動型服務，為企業打造多贏局面

網路時代來臨，消費習慣改變，所有的服務和產品都要透過軟體傳遞出去，API 就是其背後一大功臣。 API 的本質是連結兩端，提供無所不在的服務，關鍵核心就在用戶體驗，企業透過對外開放自家系統 API ，使其他開發者能夠應用在不同產品和服務上，提供消費者更多元便利的服務，常見的例子包括網路購物、旅遊比價平台、手機轉帳等，為的就是替業主吸引新客群並提升原有消費者的黏著度。在 API 經濟浪潮下，除了消費者能夠享受更便利的生活服務，企業透過分享 API 並與第三方平台串接，也能激發更多的創新應用場景，強化自身產品競爭力，開拓新商機，打造雙贏局面！

### 談 API 經濟前，先來談談什麼是 API

API 全名是應用程式介面（Application Programming Interface），可想成是串接兩端應用程式的橋樑，讓資料能夠互動進行拋接，一端輸入一端回傳，同時也能有效減輕開發者的負擔，建立新的導入渠道。以網路上常見的餐廳例子來比喻，客人（用戶端）跟服務生點餐，服務生將點餐資訊傳給廚房（應用程式），最後再從廚房將餐點送到客人手上，服務生在此就扮演了 API 的角色，也就是「傳遞資訊」。

API 的好處在於開發者不需了解所有的技術與邏輯，並且 API 具有標準化、規模化的特色，當公司有新的功能想要推出時，可直接購買有開放資料的軟體，並且透過 API 強大的資料整合能力進行串接，進而推出更符合消費者需求與經濟效益的產品。

### 發展 API 經濟，重點在\_\_\_\_\_\_\_?

API 並非這幾年才出現的新技術，歐美科技巨頭早在10幾年前便透過 API 處理大量的交易與數據，如今受到物聯網、雲端產業鏈、行動裝置的影響，API 才又越趨受到全球服務商重視，這一波新浪潮帶動了 API 經濟崛起；而發展 API 經濟的第一步在於「開放」，企業或銀行政府機關透過開放關鍵資料，將兩方資源整合，以因應快速變動的市場，同時減少內部開發耗能，進而帶來大量經濟效益。

舉例來說，銀行透過 ” 開放 API ” ( OPEN API )，將金融資料分享給第三方業者如通訊軟體 (IM) 服務商，消費者便可直接在通訊軟體中轉帳，而不用另外登入網路銀行或是行動 APP，使得金融服務能夠落實於生活中，讓民眾有更多機會與銀行互動。亦或是醫院網站串接掛號系統、機票比價網站、天氣查詢平台，甚至是疫情期間口罩、快篩搶購風潮下出現的庫存查詢 APP 等，都是開放 API 的實際應用範例。

API 經濟的商業模式很多元，其中一個是打造 API 生態系，就企業層面來說，開放 API 的提供商如銀行、保險業者等，只要將內部資源整合，並確保資料傳輸具備標準化與安全性，透過開放平台便可以有償提供給開發商進行各種應用服務的串接，進而在更短的時間內將業務觸及到不同的商業體系，增加營收。對 API 開發商來說，則能更專注在自身產品優勢，省去開發人力與時間成本，透過 API 串接即可導入更多創新服務，挖掘潛在客戶，同時為品牌帶來嶄新面貌。而就消費者層面，開放 API 能夠打造全通路的購物體驗，享受到科技所帶來的創新服務。

### API 經濟未來發展與挑戰

由小窺大，API 經濟的規模不容小覷，以軟體為核心、服務為導向，將是未來的趨勢，想要在 API 經濟中獲勝，提供好的用戶體驗是關鍵，鑑於此，企業轉型勢在必行，國內許多業者面對 Open API 也都抱持正面態度，然而企業在開放 API 時面對龐大的數據與流量，需考量如何落實 API 管理（APIM）、監控與優化，清楚掌握目前內外部 API 運用情形，建立強大的資安防護網，同時確保資料傳輸中的隱密性和存取安全性等問題，並遵循法規限制，都是一大挑戰。
