## 淺談航運

**航運（Shipping）意指透過海上船舶或者空中運輸等工具及方式來運送人及貨物。從15世紀開始，航運的蓬勃發展使得人類可以橫跨不同國家，貨物也可以在洲與洲、國與國之間流通。目前的全球貿易中，有 80%~90% 都是仰賴海上運輸。而所謂的海上運輸則包含客輪及貨輪。範圍包括各式港口、海上運具，如船舶、貨櫃等。(出處：wikipedia)**

**以台灣基隆港口為例，2020年的進出港船舶超過一萬個艘次，旅客人數達到將次 26 萬人次，貨****框卸載量更多達1百50萬。**

### 數位化轉型

<strong>以往，貨櫃傳輸給人一種 “傳統” 的印象。然而隨著時代科技的進步，船泊航運也在發展其數位化轉型。因此國際船泊運輸業者，馬士基（Maersk）、地中海航運（MSC）、赫伯羅特（Hapag-LIoyd）及海洋網聯船務（ONE）在2019年聯合創立了數位化貨櫃航運聯盟 (DigitalContainer Shipping Alliance,簡稱DCSA)。</strong>**DCSA 主要目的為建立數位化的貨櫃航運業，在這個行業中，客戶可以選擇無縫、易於使用的服務，從而靈活地滿足他們的業務和可持續發展目標。**

**通過DCSA建立的一致性和標準化的介面標準，來塑造貨櫃航運的數位未來以實現透明、可靠、易於使用、安全和環保的貨櫃運輸服務。 DCSA 的開源標準供所有人免費使用，是根據 DCSA成員、行業利益相關者和其他行業的技術專家的意見制定的。（出處：DCSA )**

**同年，台灣的航運業者，如陽明海運及長榮海運也宣佈加入 DCSA，期待透過標準化來實現航運數位化，同時也透過與其他貨櫃航運公司密切合作，找出數位時代的最佳發展路徑。**

### 智慧港口

**國際港口協會（IAPH）與航運業一項報告指出，目前國際海事組織（IMO）的一百七十四個成員國中，只有四十九個擁有有效的港口社區系統，其它港口則仰賴人工及紙本作業。也因為COVID-19 疫情爆發，加速促進全球港口數位化，採用安全的電子數據交換來簡化作業流程並有效的控管，開發智慧港口。**

**其促進智慧港口的開發，則是要藉由資料的開放及串接來達成。DCSA 訂定了一套標準化的資料開放規範，主要框架則遵循 OpenAPI 規範。開放資料需藉由 API 的串接，來串連各貨櫃運輸業者間的資料，除了可以讓相關利益者有效的實現數位化及互通性外，也可以幫助港務管理公司更好追蹤及管理進出港客/貨輪，以達到港務智慧化。**

**為了提升港務局及貨櫃輸運公司業的 API 的管理效率，此時 API 管理平台（APIM Platform）是不可或缺的好幫手。現在市面上的 API 管理平台，都提供介接格式統一及資料加密的功能。因港務及貨櫃運輸是跨公司及單位的合作，需將公司龐大的資料量開放給相關人員或外部人員使用，若平台提供與後端系統介接的便利性及可管理 API 授權的多樣性，便可大大提高 API 管理的效率，除此之外，如果平台還有提供圖形化的操作介面，讓任何人都可以馬上上手操作，不僅省下程式碼開發的工時，也可省下內部熟悉系統及管理的時間。**
