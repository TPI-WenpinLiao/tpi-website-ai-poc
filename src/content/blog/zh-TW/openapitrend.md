## 淺談開放式API (Open API)

近幾年API的應用堀起，也讓各產業對於開放API躍躍欲試。什麼是API? API全名為Appication Programming Interface，是軟體與軟體之間溝通及連接的橋梁，在幫開發者節省開發精力及時間的同時，也為數位服務提供了新的數位產品及商業模式，建立新的業務渠道 。

開放API有兩大特徵：第一是「標準化」，API的格式統一，合作雙方的資料可以相互使用、分析；第二是「規模化」，開放API能帶動更多潛在客戶使用第三方服務，同時擴大資料庫的資料，藉由流量接觸新客群，獲取更多利潤(出處：高敬原(2019)，API經濟崛起！快速串接金流，為什麼銀行「愈開放愈好賺」)。

也因為API的發展及應用堀起，目前市場上又發展出所謂的開放式API，簡單來說就是企業或機關透過開放API，讓外部人員(服務提供商或應用程式開發業者)可以存取使用，藉由API的串接，相關業者也可開發不同的服務、提供更多元的選擇，藉此擴展系統生態鏈。

舉例來說，現在大家常用的查公車時刻就是使用開放式API的最佳例子。相關單位提供及開放公車到站等訊息的API，讓民間服務提供商可自行存取，進而設計出相關的產品 (Web or APP)，如台北等公車APP。

另一個例子則是新冠肺炎(Covid-19) 疫情爆發初期，民眾掀起了一波搶口罩炫風，為了讓大家可以更清楚知道去哪裡買口罩及庫存狀況，衛生福利部中央健康保險署開放了口罩庫存及查詢相關API，讓應用程式界面開發商可以利用這些API去設計相關的應用程式 (如口罩地圖APP)，提供給需要的民眾。

### 開放式API趨勢

API發展趨勢第一步便是『開放』。用意主要為透過開放API，為產業帶來更多的創新，同時也帶來無限商機。

根據CRIFAX的預測，電信5G時代的來臨會進一步帶動開放式API的成長。CRIFAX預估全球手機連線上網的數量在未來2年內會成長到200億支。而IT、電信和網路服務業者為了因應這股潮流，也正積極的推動數位化轉型，同時也促進未來6-7年內開放式API市場的增長 (出處：CRIFAX(2019), Open Api Market Analysis Report, Global Outlook, Growth Potential, Competitive Market Share & Forecast, 2019 – 2028)。

也因為開放式API的發展，進而帶動了API生命週期管理 (Full-Lifecycle API Management, FLAPIM)工具的需求成長。2019年，全球FLAPIM市場成長了36%，帶進了17億美金的商機，在另類投資市場(Alternative Investment Market, AIM) 是成長第三快速的產業 (出處：Gartner Inc. (2020), Market Share Analysis: Full Life Cycle API Management, Worldwide – 2019)。

直至2023年，FLAPIM的複合年均增長率(CAGR) 預估會達到23%，帶來大約15億的商機。而北美也被預測是Open API產業發展最快速、市佔率最高的地區 (出處：Mr. Shelly Singh(2018), API Management Market worth $5.1 billion by 2023.)。

因為持續性的成長率及對未來成長的高期待性，各家國際大廠也紛紛投入FLAPIM相關管理工具的開發。

API管理（APIM） CAGR 預估在 2023 會成長 32.9%

### 開放API 面臨的挑戰

開放API最大的精髓便是把自家服務或資料開放讓人取用，也因此面臨了以下挑戰：

1.  資料標準化：各家API開發標準不一，所以首要課題便是制定API介接標準，把API的格式統一，讓合作雙方的資料可以相互使用及分析。

2.  資安問題：在廣泛的網路世界，要如何確保資料的隱密性、完整性、及不可被竄改性也成為了業界的一大挑戰。

3.  API生命週期管理：與企業自身的AP Server不同，開放API就是將API開放給外部人員使用，因此企業需要從一開始的API盤點、開發、部署、上/下架及API的使用授權管理都是企業客戶需考慮的部份。

### 開放API 未來發展

開放式API已被廣泛的使用在各個產業中，最有名的便是2015年在歐洲被提出的開放銀行([Open Banking](/industries/finance))。銀行透過開放API的使用使第三方開發人員 (Third-party Service Provider, TSP)夠圍繞金融機構構建應用程序和服務。從公開數據到私有數據，為帳戶持有者提供了更高的財務透明度選項。使用開源技術來實現上述目的。

其它例如政府平台 ([Open Government](/industries/government))、保險業 (Open Insurance)、醫療照顧業(Open HealthCare)，也都紛紛加進開放API的行列，期望透過開放企業服務API可以為其產業帶來的創新及擴展生態圈。

此外開放式API也被運用在數位化貨櫃航運聯盟(Digital Container Shipping Association, 簡稱DCSA，目的為制定貨櫃航運產業的資訊標準化，以推動整個航港產業的數位化發展。

開放式API為企業帶來無限可能，藉著API的使用及包裝，向市場提供更多元的服務，透過與不同類型的服務開發商合作，除了擴展業務及合作通路外，企業也可以迎來另一波的商機及創新，為企業本身及消費者帶來雙贏的局面。
