Open Banking 已成國際趨勢，各國對於金融科技各有不同見解與看法。9月份昕力資訊受越南最大軟體開發商 FPT 之邀，參與「aka Fintech Seminar 2019」，於首都河內分享台灣金融科技發展，不少越南業者也表達讚賞。面對 Open banking 的浪潮，開放是一條必要走的路，研討會中昕力資訊也提出應善用「API管理」(APIM)、「區塊鏈」(Block Chain)、「機器人流程自動化」(RPA)三大層面的解決方案，方能加速發展。

## 擁抱Open趨勢 導入API管理平台打造開放基石

金融科技浪潮之下，Open Banking 在台灣已逐漸邁開步伐，金管會已核定台灣採香港模式分三階段進行，無論哪個階段，最重要的就是「業者自律」，強調資安控管與防護等相關問題。在實現「消費者賦權」的遠景上，第一階段業者自律為重，已不少金融業者開始導入 API 管理平台。昕力資訊則表示，趨勢必定是走向開放，但在開放的同時，安全與管理規則化不可少，以昕力自有產品 API 管理平台 [digiRunner](/products/digirunner)（前身為 TSMP (ThinkPower Service Management Platform)」為例，100% 遵循開放式架構，針對 API 開發者、API 調用者、以及平台管理者三大角色進行控管，屬於最完整的管理系統。

[digiRunner](/products/digirunner) 提供 API 開發設計規範、佈署發佈、監控管理、存取權限控管、交易安全管理等等功能，同時又以「In- service deployment」與「On- demand session」兩項重要專利，達成金融業要求「服務不中斷」的最高目標。其中，「API重組」功能，則可讓既有 API 透過 [digiRunner](/products/digirunner) 平台以輕量級 web 形式在畫布上拖拉組構新的 API，讓使用更千變萬化，滿足不同的金融科技場景。

### 運用區塊鏈 打造更公平的交易資訊

而與 Open Banking 同樣是重點關鍵字的「區塊鏈」(block chain)也是不少台灣金融業者積極嘗試的方向，看中區塊鏈「不可抹滅」、「不可竄改」、「分散紀錄」的特性，將其運用於不同業務應用中。昕力資訊也提到，未來台灣產業間合作將更為緊密，區塊鏈使用將更為重要。現在台灣金融產業已提出在點數交換、外匯交易、帳務紀錄等等方面提倡使用區塊鏈技術，將「資料分散於各使用者」，也創造更多金融科技發展的機會。

### 機器人流程自動化 數位勞動力的最後一哩路

台灣金融業積極針對如何進行業務流程自動化，以增進作業效率進行諸多討論。透過導入 RPA 系統，機器人將以軟體形式模擬員工使用電腦操作行為，基礎可應用於固定且重複性高之工作，用排程方式自動化進行。此外，亦可應用於避免人為操作新舊兩系統資料交換時，造成資訊遺漏，透過 RPA 即可將操作行為解構後重組，打造機器人專用流程，幾乎可達成 0 錯誤率。

昕力資訊也分享，台灣不少業者提供 chatbot 服務，但是大多數僅能在第一線蒐集使用者需求，實際上內部處理流程仍需要人工處理，還沒辦法真正立即處理客戶問題。導入 RPA 後，chatbot 即可完整串接前端與後端系統，為機器人打造自動工作流程，一條龍完整服務客戶，這才是真正使用AI做為「數位勞動力」的最佳典範。
