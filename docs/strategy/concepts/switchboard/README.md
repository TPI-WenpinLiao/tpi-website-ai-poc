# 方向 switchboard：接點圖

把「接進既有系統」畫成整頁的主要影像。第一屏是超大字的定位句，右側是「依產業看方案」的切換（金融、政府與公部門），往下緊接一條全寬的深色接點圖：既有系統 → 昕力的產品 → 新的服務。之後每個產品家族各有一條小接線圖，OrientAI 段畫的是「企業端」的邊界。頁面依 brief 的三組判斷分底色：「是不是為您做」白底、「做得到嗎」深色帶、「安不安心」淺灰；寬螢幕左側有一個固定的目錄，列出三組問題與段落，底部是聯絡業務。字體全部換成 Noto Sans TC，標題用 900 字重。

- 原型：`index.html`（從 `file://` 直接打開，不連外部網址）
- 截圖：`shot-375.png`、`shot-375-first.png`、`shot-1280.png`、`shot-1280-first.png`

## 與另外兩個方向的差異

| 面向 | switchboard | ledger | scene |
|---|---|---|---|
| 版面 | 超大 h1 加產業切換、全寬接點圖、左側固定目錄、三組底色 | 編號欄＋主欄＋頁邊註記 | 深色場景上的玻璃卡片，hero 左文右圖 |
| 字體 | 全部 Noto Sans TC（webfont），標題 900 | 標題 Noto Serif TC，內文系統字 | 系統中文字（照現有） |
| 影像 | 圖解是主要影像，從 hero 一路出現到 OrientAI | 無影像，一張編號圖解 | 3D 靜態圖加層標籤、CSS 偽 3D |
| 色彩 | 白、深色帶、淺灰，聯絡段紫 900 | 白紙、墨色 | 全頁深色 |
| 動態 | 接線隨捲動畫出 | 無 | 按鈕上浮、圖層分開 |

| 固定聯絡入口 | 1280 寬：左側目錄底部的按鈕跟著捲動，header 不固定；375 寬：header 按鈕，不固定 | sticky header（375 寬收進選單） | header 按鈕；375 寬 sticky 底部列 |

## 放寬的限制

| 限制 | 處理 |
|---|---|
| 中文 webfont | 放寬：全頁中文改用 Noto Sans TC，400 與 900 兩個字重（`<b>`、`<h3>` 的 700 對到 900）。依 fontsource 的 unicode-range 切片只複製本頁用到的：400 有 397 個字元、14 個檔、502.8 KB；900 有 134 個字元、13 個檔、448.0 KB；合計 27 個檔、950.8 KB（`assets/fonts/`），另有 Inter、JetBrains Mono 的 latin 切片 87 KB。代價：本機用 Lighthouse 行動版網路條件（150 ms RTT、1.6 Mbps、CPU 4 倍降速）量 3 次取中位數，FCP 556 ms（備用字先畫），最後一個 woff2 在 5909 ms 才下載完，28 個字型請求；換字時整頁的內文與標題都會位移。每篇 blog 用字不同，切片數會比首頁多，`font-subsets.mjs` 要改成也管中文切片，CLS 要另外量 |
| JS 預算（初始 6 KB／延後 140 KB gzip） | 照現有，而且更少：原型沒有 `<script>`，首頁不載入 three.js |
| 3D | 放寬：首頁不用 3D，`Scene3D`、`modular-stack` 與 hero 的 `Backdrop` 都拿掉；`design-system`「設計方向」要改寫 |
| 色彩 token | 照現有的值，用法放寬：亮色頁面中間放一條 ink-950 的深色帶（production 用 `data-surface="dark"` 包住第 3–5 段），聯絡段整塊用 purple-900（現有 `--color-bg-brand-subtle` 的深色值）。P4 說大面積用中性色，紫色整塊只限聯絡段 |
| 影像規範 | 放寬：抽象 3D 渲染改成含文字的 SVG 圖解，而且出現在 hero、產品家族、OrientAI 三處。圖解文字只用事實庫的系統與產品名稱，不放數字。代價：每張圖有橫式與直式兩份（hero），產品調整或三語上線時都要改圖；圖解是 inline SVG，三語各一份 |

## 原型與 production 的差距

- 左側目錄只是錨點連結，沒有標出目前所在的段落（要 scroll spy 就需要 JS，會碰初始 JS 預算）
- 深色帶用 `border-image` 往左右延伸到整個視窗寬，同時給 section 自己的背景色讓 axe 量得到對比；production 用 `data-surface` 與全寬的 `Surface` 元件
- 連結都是 `#`；沒有 mega menu、語系切換、搜尋；375 寬的「選單」只跳到頁尾導覽
- 樣式直接寫 token 的原始值，production 改用語意 token
- 事實手打進 HTML 並去掉 U+200B；production 用 `fact('<id>')`
- 中文切片是對這一版文字算出來的（`/tmp` 的一次性 script），文字改了要重算
- 對比用 axe-core（WCAG 2.1 AA）在 375、1280 寬檢查過，沒有違規

## 待補

- 第 8 段：聯絡後多久回覆（`briefs/home.md`「待確認」第 4 項），頁面上標了「待補」
- 第 6 段的服務只有名稱，沒有說明句
- 產業切換每列的副標（「開放銀行與金融檢查」「共通性 API 規範」）、圖解的方框文字、目錄的三組問題名稱都是新寫的表述，要由人審
- 第 1 段 `fact:company-industries` 提到製造生產等其他產業，畫面上沒有引用（同 ledger）
- 375 寬第一則案例在第三屏：要嚴格做到兩次捲動內，可以把 hero 的直式接點圖移到第 4 段，代價是 375 寬的第一屏看不到接點
