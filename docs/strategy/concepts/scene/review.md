## 評審：scene

評審日期 2026-11-01，由新的 `reviewer` 依 `site-review` 評分。評審沒有讀本目錄的 `README.md`、其他方向與 `.claude/progress/`。設計概念階段不判斷通過與否，分數只供選方向。

第一印象（只看 `shot-1280-first.png` 與 `shot-375-first.png`）：一眼就看得出是替金融與政府把 API 與 AI 接進既有系統的軟體公司。h1 是畫面最大的元素，產業標籤也在第一屏。右側的發光玻璃疊層跟 SYSTEX 首屏的發光方塊屬於同一類深色科技物件，但每一層都有標籤（既有系統、digiRunner API 管理平台、AI Gateway、新的服務），所以讀得出是接入架構，不只是氛圍圖。

要改的地方：

- D2：hero 疊層要用顏色或材質分出「既有系統」（中性色）和「昕力的產品與接點」（品牌色），讓 P3 的「誰接了什麼」不用讀標籤也看得出來。發光核心以外的大面積光暈要收斂，否則跟 SYSTEX 的發光方塊太像。OrientAI 段的線框菱形要和 hero 用同一種影像語言，或換成不像另一套風格的圖解。
- D4：第 2、3、4、7 段不要都用同一種「標題 + 等大卡片格」，至少讓產品家族（可掃讀的索引）和公司紀錄（緊湊的紀錄列）換成密度不同的版型，照 P5 的分輕重。第 6 段服務框的列距要修成跟其他格線一致，現在看起來像跑版。
