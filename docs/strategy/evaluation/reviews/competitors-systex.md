# 評審：精誠資訊 SYSTEX 首頁（競品）

評審時的代號 r01。`reviewer` 只看匿名化的截圖與 HTML，不知道這一組是什麼，也沒看到其他組的分數。競品沒有 brief，也不適用昕力的設計原則：D2、C5、S1、S2、S5 標不適用，平均只算其餘項目。C1 看這家自己的定位，C3 只看主張旁有沒有具體證據，C4 用 `site-profile.md` 的主要轉換（聯絡業務），S6 依一般 B2B 首頁的慣例。以下是評審的原文，只調整標題層級。

素材限制（評審註明，評分時已考慮）：

- 規模數字是跳動的動畫，三份素材記到的數值都不同：1280 截圖是 2,400+／3+／270+／26 億，375 截圖是 2,200+／3+／225+／24 億，HTML 的 DOM 是 13,200／17／1485／145 億。截圖時設了 `prefers-reduced-motion: reduce`，數字仍在跳動
- 1280 寬「服務版圖」段的左半邊是空白，375 寬同一段的標題下方也有一大片空白。可能是地圖圖片沒有載入，也可能是設計本身留白，從素材判斷不了，照畫面原樣評

第一印象：第一屏只有發光晶片方塊的影像，加上「萬物皆數／AI生成・無限可能」兩行字。5 秒內看不出這家公司做什麼、為誰做。1280 寬時第一屏最底下露出一排分類頁籤（全球IT服務、Ai4iA、Service…），這是唯一能看出是 IT 服務商的線索。

## 門檻判斷

三份 rubric 都沒有通過：設計 2.6（D1、D6 低於 3）、文案與行銷 2.0（五個評分項都是 2）、SEO 1.0（三項都是 1）。

要改的地方：
- D1、C1：第一屏要用文字說出做什麼、為誰做，不能只靠口號和通用的科技影像。現在換掉 logo 後，和其他競品分不出來
- D3：hero 的標題要比影像更搶眼，副標不要拉開字距。頁籤段的照片拼貼縮小或移到次要位置，讓文字主張成為焦點
- D4：「服務版圖」左半的空白和 375 寬的大片空白要處理。段落之間的留白要一致
- D5、C3：規模數字直接輸出最終值，不要用會停在中間值的動畫，並標出處或年份。至少放一則具名的客戶案例或成果，原廠 logo 和客戶要分開標示。獎項從新聞輪播拉出來，放在主張旁邊
- D6：375 寬「最新動向」的卡片要修正跑版。hero 不要整屏都沒有資訊，數字卡改成兩欄或更緊湊的排法
- C2：至少有一段針對主要受眾（產業決策者）的任務或顧慮來寫，不要整頁都是新聞與公司規模
- C4：頁面主體要有明確的聯絡業務 CTA，放在證據段之後，文字要說清楚點了會怎樣。375 寬的 footer 也要有聯絡入口。客服按鈕要加上文字說明
- C6：刪掉空話型的口號。頁籤名稱統一用一種語言、一種寫法。新聞摘要改寫給首頁讀者看
- S3：title 要寫出主要業務用詞，要有一段讓人想點的 meta description，h1 要有文字，並和 hero 主標一致
- S4：段落標題改用 h2、頁籤面板標題用 h3，heading 文字要說明段落內容
- S6：補上 Organization 與 WebSite 的 JSON-LD，內容和頁面上看得到的一致
