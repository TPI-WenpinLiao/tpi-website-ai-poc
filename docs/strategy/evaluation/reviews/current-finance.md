# 評審：現站開放銀行頁（金融產業頁的對照）

評審時的代號 r05，對象 `https://www.tpisoftware.com/products/open-banking`。現站沒有金融產業頁，`page-map.csv` 把這一頁併入新站的 `/industries/finance`，所以用它當對照，對照 `docs/strategy/briefs/finance.md`。`reviewer` 只看匿名化的截圖與 HTML（渲染後的 DOM），不知道這一組是什麼，也沒看到其他組的分數。以下是評審的原文，只調整標題層級。

這一頁和 brief 的頁面類型不同（開放銀行產品頁對產業 hub），S1、C5 的低分主要反映這一點，見文末「評審依據不足」第 1 項。

截圖：[`../current/finance-1280-first.jpg`](../current/finance-1280-first.jpg)、[`../current/finance-375-first.jpg`](../current/finance-375-first.jpg)、整頁 [`1280`](../current/finance-1280-full.jpg)、[`375`](../current/finance-375-full.jpg)。理由裡的 `page-<width>-partNN.jpg` 是整頁圖由上而下每 1600 px（375 寬是 1400 px）切成的段落。

第一印象：第一屏是一張銀行建築的圖庫照片，上面疊一塊黃色色塊，寫「OPEN BANKING 開放銀行」和開放銀行的定義。5 秒內只看得出這是在介紹開放銀行這個概念，看不出昕力做什麼、為誰做，也看不出這是金融產業頁。往下捲，好幾個區塊的透明度很低（以 reduced-motion 截圖，仍停在淡出狀態）、有空的深灰方塊、紫色色塊壓住標題。

## 設計：平均 1.3，未通過

| 項目 | 分數 | 理由 |
|---|---|---|
| D1 第一屏的辨識度 | 1 | 主要文字是開放銀行的名詞定義（「在銀行客戶（消費者）的同意下，將資料開放給第三方平台…」），沒有一句說昕力做什麼，也沒有銀行、保險、證券這些對象。看圖庫的銀行建築加定義文，像金融媒體或任何一家 API 廠商的頁面，換掉 logo 就分不出是哪一家 |

| D3 視覺層級 | 2 | 第一屏的焦點清楚（黃色色塊），三階段時間軸也還清楚。之後的層級就壞了：`page-1280-part02.jpg` 中段的三張階段卡片透明度極低，digiRunner 的功能說明幾乎讀不到，反而是背景的大號數字 1、2、3 比內文顯眼；`page-1280-part03.jpg` 的「如何選擇 API 管理平台？」h2 被一條紫色色條整個蓋住；`page-1280-part04.jpg` 的 3 個空深灰方塊比卡片內文還搶眼 |

要改的地方：
- D1：第一屏要用文字寫出昕力替銀行、保險、證券處理什麼（brief 第 1 段）；拿掉以開放銀行定義當主文字的做法
- D2：拿掉圖庫照片、通用 icon 比較圖、浮動吉祥物和同款編號卡片
- D3：主要內容不能停在淡出或被色塊蓋住的狀態。焦點順序改照 brief
- D4：統一段落間距，移除沒有內容的空白和空方塊

- D6：375 寬不能有元素壓住文字；比較圖這類橫向圖解要重新安排或拿掉

## 評審依據不足

- `briefs/finance.md` 寫的是新的 `/industries/finance` hub 頁，評審對象卻是現站開放銀行頁的網址與內容。brief 與 rubric 都沒寫：舊網址併入新頁時，評審應該照目標 brief 評，還是照原頁的意圖評。這次照 prompt 的指示用 finance brief 評，S1、C5 的分數主要反映「不是 brief 要的頁面類型」
- `design-principles.md` 的 P1 與 P5 是照首頁寫的，沒寫產業頁的第一屏要有哪些元素
- D1 要求對照 `competitors.md`，但它只比較首頁
- S2 的 5 分錨點要「有競品沒有的資訊」，但 `search-intent.md` 沒記哪些子題前幾名都沒有
- 截圖說明寫「以 `prefers-reduced-motion: reduce` 截取，動畫顯示結束狀態」，但截圖裡多個區塊仍是低透明度。`site-review` 沒說明遇到這種情況時，要當成頁面的實際呈現評，還是當成截圖的問題。這次當成頁面實際呈現評（D3、D6），如果是截圖的問題，這兩項可能會偏低
