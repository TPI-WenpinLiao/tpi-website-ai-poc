# 評審：凌群電腦 Syscom 首頁（競品）

評審時的代號 r08。`reviewer` 只看匿名化的截圖與 HTML，不知道這一組是什麼，也沒看到其他組的分數。競品沒有 brief，也不適用昕力的設計原則：D2、C5、S1、S2、S5 標不適用，平均只算其餘項目。以下是評審的原文，只調整標題層級。

截圖：[`../competitors/syscom-1280-first.jpg`](../competitors/syscom-1280-first.jpg)、[`../competitors/syscom-375-first.jpg`](../competitors/syscom-375-first.jpg)、整頁 [`1280`](../competitors/syscom-1280-full.jpg)、[`375`](../competitors/syscom-375-full.jpg)。理由裡的 `page-<width>-partNN.jpg` 是整頁圖由上而下每 1600 px（375 寬是 1400 px）切成的段落。

第一印象：1280 寬的第一屏，5 秒內只看得出這是一家做「GEN AI 系統整合服務」的台灣 IT 公司。看不出它服務誰，也看不出整家公司的定位。375 寬的 banner 被裁掉，主標只剩「服務」兩個字，第一屏實際上是「多元專業解決方案」的卡片。

## 設計：平均 2.0，未通過（D2 不適用，平均只算 D1、D3–D6）

| 項目 | 分數 | 理由 |
|---|---|---|
| D1 第一屏的辨識度 | 2 | `page-1280-first.jpg` 的 banner 寫「GEN AI 系統整合服務」，標語是「串接資料 × 強化效能 × 企業升級」。這只是 5 張輪播之一（HTML 有 5 個 `swiper-slide`：GEN_AI、Cloud、ESG、MBNQA、TEA），講的是單一服務，不是公司定位，也沒有對象。看得出是 B2B IT 服務商，但沒有和 SYSTEX、FPT 等家區隔的地方，紫藍光流的背景也是通用的科技風格。`page-375-first.jpg` 裁到只剩「服務」與「企業升級」，連做什麼都讀不出來。所以 1280 寬勉強到 3 分，375 寬低於 3 分，取 2 分 |
| D2 與設計原則一致 | 不適用 | 不適用昕力的設計原則 |
| D3 視覺層級 | 2 | banner 有第一眼焦點。往下的「多元專業解決方案」六張卡片（`page-1280-part01.jpg` 中段）各用一種飽和色（紫、藍、綠、青、黃、紅），加上大號英文字（SYSCOM GO、CLOUD、RETAIL 等），六張的視覺權重一樣，互相搶焦點，看不出哪一項是主力。「熱門焦點」段的六個彩色圓圈也一樣平均。聯絡段（`page-1280-part02.jpg`）在 1280 寬時，右欄只有「聯絡我們」的標題與說明，整片留白，表單掉到下方並占滿全寬；送出按鈕「立即聯繫」沒有按鈕外觀，看起來是一行普通文字，最該被看到的元素反而最弱 |
| D4 版面與節奏 | 2 | banner 和「多元專業解決方案」之間有一大段空白（`page-1280-first.jpg` 約 425–540px），卡片段卻四邊貼齊、沒有間隔，密度落差看起來不是刻意安排的。聯絡段在 1280 寬時左欄是 logo、地址與獎項，右欄空白，下面是全寬表單，左右失衡，像是版面出錯。頁面很短，段落之間沒有節奏可言 |
| D5 證據的呈現 | 2 | 全頁只有一項證據：聯絡段左欄的獎項圖（第 27 屆國家品質獎產業支援典範類、2026 台灣精品獎，`page-1280-part02.jpg` 約 600–840px）。它排在社群入口之後、表單旁邊，讀者捲到底才看到。沒有案例、客戶名、客戶 logo 或規模數字。銀行或政府的決策者要的「誰用過、成效如何」完全找不到 |
| D6 窄螢幕 | 2 | 解決方案卡片在 375 寬時有重新排過：改成單欄的短卡，「more」按鈕和標題放在同一行（`page-375-part01.jpg`），「熱門焦點」改成 2 欄（`page-375-part02.jpg`），這部分有為窄螢幕調整。但 banner 的文字做在背景圖裡，被裁到只剩「服務」（`page-375-first.jpg`），第一屏唯一的定位訊息消失了，屬於跑版 |

要改的地方：
- D1：第一屏要有一句以文字輸出、不隨輪播換掉的公司定位，說出做什麼、為哪些產業做。現在第一屏只有輪播中某一張的單一服務名稱，375 寬時還被裁掉
- D3：六張解決方案卡片要分出主次，讓讀者知道哪些是主力。聯絡段的送出按鈕要有按鈕的樣子，1280 寬時表單要放進右欄空著的位置，不要讓它掉到下方
- D4：banner 與第一段之間的空白、聯絡段左右不平衡的問題要修，讓間距看起來是有意的安排
- D5：獎項之外，要補案例、客戶或規模等證據，並往前移到讀者判斷要不要聯絡之前，不要只放在表單旁
- D6：banner 的主標不能做在圖片裡；375 寬要看得到完整的定位句

## 文案與行銷：平均 2.4，未通過（C5 不適用，平均只算 C1–C4、C6）

| 項目 | 分數 | 理由 |
|---|---|---|
| C1 定位清楚（看它自己的定位） | 2 | 頁面上沒有任何一句話說明凌羣整家公司做什麼、為誰做、為什麼選它。唯一的定位文字在 banner 圖裡（「GEN AI 系統整合服務」），只是一項服務，而且會被輪播換掉。段落標題「多元專業解決方案」是泛稱。meta description 有一句定位（「國內主要的資訊服務廠商，服務據點橫跨台灣、日本、美國及泰國…」），但頁面上看不到 |
| C2 對受眾的價值 | 2 | 解決方案卡片只有產品或分類名稱加「more」（SYSCOM GO、雲端解決方案、永續發展 ESG、智慧零售雲、AI 智能解決方案、更多產品 & 服務），沒有寫能幫讀者解決什麼、帶來什麼成果。「熱門焦點」是公司自己的電子報、Facebook、YouTube、Podcast 入口，對評估廠商的決策者沒有用。站在讀者角度的只有聯絡段的一句「我們會立即派專業顧問提供您諮詢」 |
| C3 證據支撐 | 2 | 主張（banner 的「強化效能」「企業升級」、段落標題的「多元專業」）旁邊都沒有證據。全頁唯一具體的證據是聯絡段的獎項圖（國家品質獎、台灣精品獎），而且是圖片，沒有 alt（`<img src="…award-img.png">`）。沒有數字、客戶或案例成果 |
| C4 CTA 與轉換路徑（主要轉換：聯絡業務） | 3 | 首頁底部直接放聯絡表單，目標符合主要轉換。說明句「請留下您的聯繫資料，我們會立即派專業顧問提供您諮詢」講清楚了送出後會發生什麼，按鈕文字「立即聯繫」也清楚。但這是全頁唯一的 CTA：導覽列（新聞＆活動、關於凌羣、企業徵才、永續發展 ESG、投資人關係、合作夥伴、相關網站）沒有聯絡入口，banner 與卡片段也沒有。讀者要捲過社群入口才到得了，位置偏晚 |
| C5 符合 brief | 不適用 | 沒有對應的 brief |
| C6 語氣與文字品質 | 3 | 文字很少，沒有錯字。但「多元專業解決方案」「熱門焦點」是空泛的標題；卡片按鈕用英文「more」，和中文頁面不一致；同意條款「本人同意本公司提供之個人資料保護法規定」語意不通（同意的是公司的個資政策，不是「法規定」）；meta description 用「…」截斷 |

要改的地方：
- C1：用文字寫出整家公司的定位（做什麼、為哪些產業、和別家差在哪），放在第一屏，不要依賴輪播圖
- C2：每張解決方案卡片補一句它幫客戶解決的問題或帶來的成果，不要只有名稱。「熱門焦點」對決策者的價值低，要重新考慮放在首頁的理由
- C3：主張旁邊要放具體證據（客戶、案例成果、規模數字），獎項要有可讀的文字
- C4：導覽列與第一屏要有聯絡入口，讓已經準備好的讀者不必捲到底
- C6：把空泛的段落標題改成說得出內容的文字，統一「more」的語言，修正同意條款的句子

## SEO：平均 1.3，未通過（S1、S2、S5 不適用，只評 S3、S4、S6）

| 項目 | 分數 | 理由 |
|---|---|---|
| S1 搜尋意圖對應 | 不適用 | |
| S2 主題涵蓋 | 不適用 | |
| S3 title、description 與 h1 | 1 | title 是「HOME - 凌羣電腦 THE SYSCOM GROUP」，除了公司名只有「HOME」。description「為國內主要的資訊服務廠商，服務據點橫跨台灣、日本、美國及泰國等，成為國內少數提供...」少了主詞，而且被截斷在「...」。頁面沒有 h1。banner 的主標是背景圖（`style="background-image:url('…GEN_AI_xl.png')"`），沒有文字也沒有 alt |
| S4 heading 結構 | 2 | 沒有 h1。順序是 h2「多元專業解決方案」→ h5 六張卡片的標題（從 h2 直接跳到 h5）→ h2「熱門焦點」→ h3「聯絡我們」→ 兩個 modal 的 h5「通知」。卡片的 h5 是產品或分類名稱，看得出一部分內容。但「熱門焦點」是泛稱，modal 的「通知」不是內容，層級也不正確 |
| S5 內部連結 | 不適用 | |
| S6 結構化資料與內容一致 | 1 | HTML 裡沒有 `application/ld+json`。公司首頁慣例要有的 Organization（名稱、logo、地址、電話、email）都沒有，即使頁面上已經顯示地址、電話與 email |

要改的地方：
- S3：title 改成公司名加上它做什麼，拿掉「HOME」。description 寫完整的一句，不要截斷。加一個以文字輸出、說明公司定位的 h1
- S4：補上 h1，卡片標題改成照順序的 h3，「熱門焦點」改成說得出內容的標題，modal 的「通知」不要用 heading
- S6：加上 Organization JSON-LD，內容和頁面上的名稱、logo、地址、電話、email 一致

## 門檻判斷

三份 rubric 都沒通過（設計 2.0、文案與行銷 2.4、SEO 1.3），都有低於 3 分的項目。問題集中在定位（只存在於輪播圖片裡，沒有文字也沒有 h1）與證據（全頁只有一張獎項圖）。優點是首頁直接放了短表單，表單旁的說明講清楚送出後會發生什麼。
