第一批（#201），評審時的代號 r01，對象是 PR #206 在 `9121f11` build 出的 `/aiso`，對照 `docs/strategy/briefs/aiso.md`。`reviewer` 只看匿名化的截圖與 `dist/` 的 HTML。
