# 評審：試點舊版首頁

評審時的代號 r11，對象是 PR #176 合併前的 `main`（818988f）build 出的 `/`，對照 `docs/strategy/briefs/home.md`。`reviewer` 只看匿名化的截圖與 `dist/` 的 HTML，不知道這一組是什麼，也沒看到其他組的分數。以下是評審的原文，只調整標題層級。

截圖：[`../old/home-1280-first.jpg`](../old/home-1280-first.jpg)、[`../old/home-375-first.jpg`](../old/home-375-first.jpg)、整頁 [`1280`](../old/home-1280-full.jpg)、[`375`](../old/home-375-full.jpg)。理由裡的 `page-<width>-partNN.jpg` 是整頁圖由上而下每 1600 px（375 寬是 1400 px）切成的段落。

## 評審依據不足

1. `docs/strategy/briefs/home.md` 同時有兩套段落結構：開頭「製作階段的版本（#167）」寫 5 段，主體「段落結構」寫 8 段；`design-principles.md` P5 也寫「只保留 brief 的 8 段」，但檔頭的定案改成 5 段。C5、D3 沒寫要以哪一版為準
2. 截圖用 `prefers-reduced-motion: reduce` 截取，產品段（`scene-chapter`）在 1280 寬留下大片空白。rubric D4、D6 與 `site-review` 都沒寫：依賴捲動與 3D 的章節在減少動態的畫面下，該當成實際版面評，還是當成截圖的限制。本次當成實際版面評，因為減少動態的訪客看到的就是這個畫面
3. `rubrics/design.md` D1 的錨點重疊：3 分是「看得出 B2B 軟體公司，但說不出跟競品的差別」，1 分包含「和 `competitors.md` 任一家可互換」。說不出差別幾乎等於可互換，同一個畫面可以同時符合兩個錨點
4. `CLAUDE.md`「內容規則」把「產品功能」列為事實，但產業卡、產品家族副標這類一句話的描述算事實還是表述，`messaging.md` 和 C3 都沒有界定
5. `rubrics/seo.md` S2 5 分要求「有競品沒有的資訊」，但 `search-intent.md` 只記錄前幾名的共同子題，沒有列出競品缺了哪些子題，這一條沒有可對照的依據
