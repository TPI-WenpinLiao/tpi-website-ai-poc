- `.claude/skills/site-review/rubrics/copy-marketing.md`「評分提示」C3：沒寫 meta description 與 JSON-LD 的文字算不算「主張」。這次主文都沒問題，只有 description 用了 messaging 明寫不用的說法。我照 brief「description」的明令與 messaging 第 15 項判定它在 2 分上限的範圍內，但 rubric 本身沒有寫清楚。
